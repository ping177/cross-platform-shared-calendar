# v0.1.20 — Mobile Gesture Navigation

## Frozen scope / implementation plan

User approved both scopes on 2026-10-08 after the read-only audit. Preserve existing React state navigation, layout, buttons, filters and snapshots.

1. Calendar: right = previous, left = next; Today ±1 day, Week ±7 days, Month ±1 month. Buttons and gestures share date calculation. Date cells, display cards and ordinary content can start gestures. Any Sheet/Dialog/selector blocks background navigation.
2. Module lists: right swipe calls existing back entry. Tasks → Hub; completed → Tasks; Review history / Lists overview → Hub; Important Dates → existing back callback. Main page content is the surface, without an edge restriction.
3. Safety: touch-only Pointer Events, ref-held recognition, vertical-scroll priority, multi-touch/cancel reset, local `pan-y pinch-zoom`, stable trailing-click guard. Input/select/drag/dangerous controls excluded; display cards explicitly opt in. Busy/confirmation/Portal surfaces block background gestures.

## Ordered slices / verification

- Recognition + Calendar slice: pure recognizer and click guard in `src/lib`, Hook in `src/components`, shared period calculation and Calendar mounting in `src/App.tsx`. Verify deterministic Node tests plus Calendar regressions.
- Module slice: wire the same Hook to four list components and preserve their existing callbacks and state. Verify real component handlers with injected hooks/data; no network or real accounts.
- Closeout: review scoped diff, TypeScript/build, relevant regression tests, `git diff --check`; record results and pending iPhone PWA acceptance in governance docs.

Use existing TypeScript/React/Tailwind style (single quotes, semicolons), existing Node/Vite test fixtures and installed dependencies. Commands: `node --experimental-strip-types --test tests/mobile-gesture*.test.ts`, `node_modules/.bin/tsc -b`, `npm run build`, relevant `node --experimental-strip-types --test tests/...`, `git diff --check`. Local port remains 5175 with strictPort.

## Boundaries / acceptance gate

No global swipe-back, Sidebar, bottom-tab swipe, detail/Sheet closing gestures, business-operation gestures, dirty/busy redesign, backend/SQL/RLS/RPC/Edge/scheduler changes, third-party gesture dependencies or new navigation controller/history. Reference Food Expiry v0.3.5 read-only; do not import its navigation architecture or Sidebar-specific thresholds.

Automatic PASS is not iPhone PWA PASS. No commit/push/deploy/Production modification authorized. Before authenticated acceptance, establish actual frontend target and deployed backend compatibility without exposing secrets; if environment alignment cannot be established within authorization, stop at that gate. Installed Production PWA cannot run this local patch until a separately authorized frontend release. User owns logged-in and real-device acceptance.
